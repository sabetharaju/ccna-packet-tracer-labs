# CCNA Packet Tracer Labs

A collection of hands-on Cisco Packet Tracer labs completed as part of CCNA 200-301 study, documenting core networking concepts through configuration, verification, and packet-level analysis.

## Labs

| Lab | Topic | Key Concepts |
|---|---|---|
| [NAT Configuration](./nat-configuration) | Network Address Translation | Static NAT, PAT (NAT Overload), inside/outside local/global addressing |
| [VLAN & Access Ports](./vlan-access-port) | VLANs and Switching | VLAN creation, access port assignment, Layer 2 broadcast domain isolation |
| [Spanning Tree Protocol](./spanning-tree) | Loop Prevention | Per-VLAN root bridge election, Root Guard, port roles/states |
| [Life of a Packet](./life-of-packet) | End-to-End Packet Flow | Encapsulation/decapsulation, ARP resolution timing, Layer 2/3 interaction |

## Why This Repo

Each lab was built and configured in Cisco Packet Tracer during CCNA 200-301 study, then documented here with topology diagrams, configuration steps, and verification command output to demonstrate practical understanding beyond theory.

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI (Router/Switch configuration)
